RALPH DESIGNS — PORTFOLIO UPGRADE
================================

This package is a static portfolio website for Ralph Designs.

FEATURED PROJECTS
-----------------
01 — DON MACCHIATOS
Brand + campaign design. 8 supplied project images are included.

02 — 3R SPORTSWEAR
Sportswear / sublimation design. 3 supplied apparel images are included.

03 — RKJ APPAREL
Apparel graphic showcase. 3 supplied apparel images are included.

04 — ACT
Sports media + event design. 5 supplied ACT images are included.

INTERACTIONS
------------
- Animated page loader
- Scroll reveal and staggered project entrance
- Cursor glow / ring on desktop
- Mouse-position card lighting
- Hero parallax
- Project hover zoom
- Project filtering
- Full project case-study modal
- Multi-image gallery inside each project
- Gallery thumbnails
- Previous / next navigation
- Keyboard ArrowLeft / ArrowRight navigation
- Escape to close
- Back-to-top control
- Reduced-motion support
- Responsive mobile layout
