### Changing a cover image
The large image visible on the portfolio card is the first gallery image. Change the first image in the corresponding `galleries` object inside `script.js`.

### Changing project text
Project titles, category labels, descriptions, and card text are in `index.html`.

### Adding more gallery images
Add a new `[path, alt text]` entry to the correct gallery array in `script.js`.

No external JavaScript animation library is required.
